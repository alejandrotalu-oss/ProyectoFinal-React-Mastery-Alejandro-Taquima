# Gestor de Tareas - React Mastery

Proyecto final desarrollado con React y Vite que permite gestionar tareas mediante operaciones CRUD.

## Funcionalidades

- Crear nuevas tareas.
- Visualizar la lista de tareas.
- Editar tareas existentes.
- Eliminar tareas.
- Asignar estados a las tareas:
  - Pendiente
  - En progreso
  - Completada
- Navegación entre páginas mediante React Router.
- Persistencia de datos utilizando LocalStorage.

## Tecnologías utilizadas

- React
- Vite
- React Router DOM
- JavaScript
- CSS
- LocalStorage
